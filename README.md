# Lab-Exercise-2
# AIM

To design a basic mobile and web layout for an existing case study by applying Gestalt principles, UI elements, design patterns, interaction behaviors, usability principles, and a suitable brand logo created using Canva.

# ALGORITHM
Select an existing case study and identify its target users and requirements.
Create a basic layout structure for both mobile and web interfaces.
Apply Gestalt principles such as proximity, similarity, alignment, continuity, and common region to organize the interface.
Incorporate UI elements such as buttons, navigation bars, cards, icons, images, text fields, and menus.
Apply suitable design patterns to maintain consistency and ease of navigation.
Define interaction behaviors such as button actions, navigation, feedback, and error handling.
Apply usability principles such as simplicity, consistency, visibility, accessibility, and user feedback.
Create a simple brand logo using Canva according to the selected color, typography, and branding guidelines.
Integrate the logo into both mobile and web layouts.
Review the final designs for visual consistency, usability, and responsive behavior.
